# Security policy

Report security vulnerabilities privately to **support@autophish.io**. Include the affected app and Nextcloud versions, impact and a minimal reproduction using synthetic data. Do not include API keys, credentials or customer data, and do not disclose vulnerability details in a public issue before coordinated remediation.

Security fixes target the latest released app version and the Nextcloud versions declared in `appinfo/info.xml`. The integration requires an administrator-configured AutoPhish account and API key; see the [service privacy policy](https://autophish.io/privacy/service) for data processing information.
